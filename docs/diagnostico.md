# Diagnóstico de la versión inicial

Versión analizada: tag `estado-inicial`. Todo el sistema está en `src/GestorSolicitudes.ts` (240 líneas) y el recorrido de prueba en `src/demo.ts`.

## Calidad externa

Desde la mirada del usuario el sistema funciona: `npm run demo` registra solicitudes, rechaza datos incorrectos con un mensaje, asigna responsables, respeta el circuito de estados, busca con filtros y genera el reporte con los totales correctos (ver `docs/evidencias/antes/demo.txt`).

## Calidad interna

| Aspecto          | Situación en la versión inicial                                                                                |
| ---------------- | -------------------------------------------------------------------------------------------------------------- |
| Mantenibilidad   | Una sola clase hace todo. Agregar un tipo de solicitud obliga a tocar dos métodos distintos.                   |
| Legibilidad      | Nombres como `lst`, `d`, `p`, `x`, `r`; métodos de 48 y 55 líneas.                                             |
| Testeabilidad    | La lógica escribe en disco y por consola; no se puede probar una regla sin generar archivos. No había pruebas. |
| Acoplamiento     | La lógica depende directamente de `fs` y de `console.log`.                                                     |
| Evolución futura | Pasar a una base de datos o a una interfaz web obliga a reescribir la clase completa.                          |

Análisis estático (`npm run lint`): 83 errores. Métricas (`npm run metricas`): 5 métodos superan la complejidad 8 (máximo 17 en `generarReporte`).

## Orden de corrección

1. CS-12: prueba de caracterización antes de tocar el código (`tests/caracterizacion.test.ts`).
2. CS-10 y CS-08: separar la persistencia y dejar de silenciar errores.
3. CS-05, CS-06 y CS-07: tipos del dominio, tabla de reglas y excepciones.
4. CS-11, CS-04 y CS-09: clases `Solicitud` y `Estudiante`, eliminar duplicación y renombrar.
5. CS-03, CS-02 y CS-01: objetos de parámetros, dividir el reporte y repartir responsabilidades.
